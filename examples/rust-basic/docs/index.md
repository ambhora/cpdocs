# Rust example

This example uses Cargo plus nightly rustdoc JSON. Its `batch` and `checked` Cargo features are
considered independent feature sets automatically, so each is documented once.

The complete crate remains available in the file hierarchy, including the implementation-only
`src/internal.rs`, while only public Rust API appears in the API hierarchy.

See the [generated Rust API](api.md).
