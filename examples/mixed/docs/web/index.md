# geom

A C++ library and its Python package, declared as two units of one CMake project.

The main entry points of the API:

- @apidocs::geom::vector3
- @apidocs::geom::dot
- @apidocs::geom::dot_many
- @apidocs::pygeom.dot

The [API reference](api.md) lists every published version.
